# Kilo Autonomous Rules

Mode: Headless Autonomous

## Core Directives

1. Build the app fully from start to finish.

2. NEVER stop to ask the user for confirmation, input, or permission.

3. If you run into installation, dependency, or compilation errors, read the logs and recursively fix them yourself.

## Quality Gate

4. Create an automated test script `npm test` or equivalent).

5. Run the tests. Do not consider the job complete until all tests pass with 0 errors.
